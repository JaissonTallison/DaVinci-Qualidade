# Terceiros

> **Status:** em uso · **Serviço:** `seguranca` · **Atualizado em:** 15/10/2026
> Referência: NR-1 (a contratante exige da contratada o gerenciamento de riscos dos trabalhadores dela). Regras decididas por nós (decisão Q9).

| Regra                                                                                                                    | Por quê                                 |
| ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------- |
| CNPJ válido e único na empresa                                                                                           | Cada terceira, um cadastro              |
| Liberada só com contrato vigente e PGR, PCMSO e ASO válidos hoje; qualquer outro documento vencido também gera pendência | É o mínimo para entrar e trabalhar      |
| Documento novo do mesmo tipo substitui o anterior (vale o de validade mais longa); o antigo fica no histórico            | Renovação sem apagar nada               |
| A pendência aparece escrita ("PCMSO não enviado", "PGR vencido em 10/09/2026")                                           | Quem está na portaria sabe o que cobrar |
| Arquivos dos documentos em Anexos                                                                                        | Evidência para auditoria                |
