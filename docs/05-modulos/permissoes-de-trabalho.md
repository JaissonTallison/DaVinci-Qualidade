# Permissões de trabalho (PT)

> **Status:** em uso · **Serviço:** `seguranca` · **Atualizado em:** 15/10/2026
> Referências: NR-35, NR-33, NR-10 e trabalho a quente. Regras decididas por nós (decisão Q9).

Ciclo: solicitada → liberada → encerrada; cancelada antes do encerramento, com motivo. Numeração `PT-AAAA-NNN`.

| Regra                                                                    | Por quê                                |
| ------------------------------------------------------------------------ | -------------------------------------- |
| Vale no máximo 12 horas; o fim não pode ter passado ao solicitar         | Uma jornada; no dia seguinte, outra PT |
| Liberar exige `seguranca.liberar-pt`, e quem solicitou não libera        | Dupla checagem                         |
| Liberada com o fim passado aparece com horário vencido até ser encerrada | Encerramento formal, área liberada     |
| Horários em hora de Brasília; aceita anexos                              | Como é preenchida e conferida no local |
